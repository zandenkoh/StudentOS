# StudentOS Demo

A mobile-first cinematic Next.js demo for StudentOS, an AI student operating system that turns messy school commitments into a clear executable plan.

## Routes

- `/` - full StudentOS demo flow from chaos to final plan
- `/goal` - focused goal command ingestion demo

## Run Locally

```bash
npm install
npm run dev
```

Open `http://localhost:3000`.

## Verify

```bash
npm run lint
npm run build
```

All demo content is local mock data. No auth, database, API keys, OCR, or backend integrations are required.
